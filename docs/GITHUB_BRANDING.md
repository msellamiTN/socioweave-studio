## Social preview image

Recommended GitHub social preview: 1280 × 640 px.

Design:
- Deep Navy background (#111827).
- Symbol at left, wordmark SOCIOWEAVE.
- Subtitle: “SOCIAL & ORGANISATIONAL STRATEGIES FOR LLM AGENT DECOMPOSITION”.
- Tagline: “From complex prompts to collaborative intelligence.”
- Indigo-to-violet weave motif with teal central node.
- Keep text inside the central safe area; avoid small details.

Upload through: Repository → Settings → General → Social preview → Edit → Upload an image.

## Repository avatar / organisation mark

GitHub repository avatars are inherited from the owner account. Use `assets/brand/socioweave-symbol.svg` as the source artwork when creating a square PNG (512 × 512 recommended) for any profile or organisation branding control that accepts an uploaded image.

## README preview

The root README uses relative SVG assets. GitHub renders SVG images in Markdown. The full wordmark and icon are stored under `assets/brand/`.

## Favicon and web app

Use `assets/brand/favicon.svg` as the browser favicon when the web application is added. Export PNG variants only for systems that do not support SVG favicons.

## Important

Repository description, topics, social preview, and owner avatar are GitHub settings. File commits cannot automatically change all those settings. Apply the settings above in the GitHub UI after the branding assets are committed.
